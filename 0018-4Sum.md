# 0018 - 4Sum (Medium)

## Problem

Given an integer array `nums` of length `n` and an integer `target`, return **all unique quadruplets** `[nums[a], nums[b], nums[c], nums[d]]` such that:

- `0 <= a, b, c, d < n`
- `a`, `b`, `c`, and `d` are **distinct**
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

The answer can be returned in **any order**.

---

## Examples

### Example 1

Input:  
`nums = [1,0,-1,0,-2,2], target = 0`  

Output:  
`[[-2,-1,1,2], [-2,0,0,2], [-1,0,0,1]]`

---

### Example 2

Input:  
`nums = [2,2,2,2,2], target = 8`  

Output:  
`[[2,2,2,2]]`

---

## Solution Idea (Sorting + Two Pointers)

This is an extension of the **3Sum** pattern.

1. **Sort** the array first.  
2. Fix two indices `i` and `j` with two nested loops.  
3. For each pair `(i, j)`, use **two pointers**:
   - `left` starts from `j + 1`
   - `right` starts from `n - 1`
4. Compute the sum:  
   `s = nums[i] + nums[j] + nums[left] + nums[right]`
   - If `s == target`:  
     - Add the quadruplet to the result.  
     - Move both pointers and **skip duplicates**.
   - If `s < target`: move `left` to increase the sum.
   - If `s > target`: move `right` to decrease the sum.
5. To avoid duplicate quadruplets:
   - Skip same `nums[i]` as previous `i`.
   - Skip same `nums[j]` as previous `j` for the same `i`.
   - After finding a valid quadruplet, skip duplicate values for `left` and `right`.

---

## Complexity

- Let `n` be the length of `nums`.
- Sorting: `O(n log n)`
- Two nested loops + two pointers: `O(n^3)`

Overall:

- **Time:** `O(n^3)`  
- **Space:** `O(1)` extra (ignoring output list)

---

## Python Code (Final with Comments)

```python
class Solution:
    def fourSum(self, nums: List[int], target: int) -> List[List[int]]:
        # Sort the array to use two pointers and handle duplicates
        nums.sort()
        n = len(nums)
        res: List[List[int]] = []
        
        # First index i
        for i in range(n - 3):
            # Skip duplicate values for i
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            
            # Second index j
            for j in range(i + 1, n - 2):
                # Skip duplicate values for j (for this fixed i)
                if j > i + 1 and nums[j] == nums[j - 1]:
                    continue
                
                left, right = j + 1, n - 1
                
                # Two-pointer scan for the remaining two numbers
                while left < right:
                    s = nums[i] + nums[j] + nums[left] + nums[right]
                    
                    if s == target:
                        res.append([nums[i], nums[j], nums[left], nums[right]])
                        
                        # Move both pointers and skip duplicates
                        left += 1
                        right -= 1
                        while left < right and nums[left] == nums[left - 1]:
                            left += 1
                        while left < right and nums[right] == nums[right + 1]:
                            right -= 1
                    
                    elif s < target:
                        # Need a larger sum
                        left += 1
                    else:
                        # Need a smaller sum
                        right -= 1
        
        return res
